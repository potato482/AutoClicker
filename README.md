# 概要
Windowsで動作する自動クリッカーです。  
左クリックを押している間だけ、高速でクリックされます。  
マウス中ボタンでON/OFFを切り替えることができます。
# 導入方法
このプロジェクトのautoclick.exeをダウンロードしてください。  
または、renda.cppを次のようにコンパイルしてください。  
`g++ renda.cpp -o autoclick.exe -static`  
# 使い方
コマンドライン上でautoclick.exeを実行してください。  
マウス中ボタンを押すと、クリッカーが起動します。  
クリッカー起動中、左クリックを押すと、自動クリックが始まります。  
Ctrl+Cでこのプログラムを終了してください。
